# Web interface (TUM-RC calculator)

Redesigned web front-end for the TUM Risk Calculator, corresponding to **Fig 4
(TUM-RC model and output)** in the manuscript. It presents the risk of
clinically significant prostate cancer (ISUP ≥ 2) from three externally
validated models side by side:

- **TUM-RC** — TUM Risk Calculator (this study)
- **SPCC** — Stanford Prostate Cancer Calculator
- **PCRC-MRI** — Prostate Cancer Risk Calculator (MRI)

All three risks are computed client-side in `index.html` from the patient
inputs (age, PSA, PI-RADS, prostate volume, DRE, prior negative biopsy). The
TUM-RC logistic-regression coefficients used here are identical to the `coef`
matrix in the repository's top-level `app.R`.

Live version: https://oksana-pcrc.melihy.net

## Files

| File | Description |
| --- | --- |
| `index.html` | The interface: markup, styling, and the risk-model logic (the `Component` class holds the TUM-RC / SPCC / PCRC-MRI functions). |
| `support.js` | Runtime that renders the interface. Generated by Claude Design (`claude.ai/design`) — do not hand-edit. |
| `vendor/react.production.min.js`, `vendor/react-dom.production.min.js` | React 18.3.1 (UMD), vendored so the page runs with no external/CDN dependency. |

## Running locally

The page is fully static — serve the `web/` folder with any static file server
and open it in a browser:

```
cd web
python3 -m http.server 8000
# then open http://localhost:8000/
```

Opening `index.html` directly via `file://` also works in most browsers.
